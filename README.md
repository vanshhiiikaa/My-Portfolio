## Local Setup
1. Clone the repository:
```bash
git clone https://github.com/vanshhiiikaa/My-Portfolio.git
```

2. Open the project folder:
```bash
cd My-Portfolio
```

3. Open `index.html` in your browser, or run a local server:
```bash
python -m http.server 8000
```

Then visit:
```bash
http://localhost:8000
```
